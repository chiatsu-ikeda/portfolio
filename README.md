# Portfolio

`index.html` をブラウザで開くと表示できます。HTML・CSS・JavaScriptのみで構成され、ビルドは不要です。

## 編集する場所

- `index.html`：氏名、プロフィール、メールアドレス、実績の紹介文とリンク
- `assets/`：掲載サイトのプレビュー画像
- `style.css`：配色・レイアウト
- `script.js`：年の表示・画像読み込みエラー時の処理

実績は指定された4サイトを掲載し、担当範囲を「全ページのコーディング・WordPress実装」と明記しています。
氏名・経験・スキル・連絡先は提供情報を反映済みです。React・TypeScriptは基本レベルとして記載しています。
管理画面の改修経験は「管理画面のカスタマイズ」と表現しています。制作年や各案件のプラグインは未確認のため記載していません。
お問い合わせフォームは設けず、メールリンクのみ掲載しています。
Google Fontsを使用しています。オフラインでも代替フォントで表示できます。
